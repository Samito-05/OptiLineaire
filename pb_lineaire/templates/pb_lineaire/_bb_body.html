Procédure du cours : Branch-and-Bound

  1. Résoudre la relaxation LP du nœud courant (Simplexe ou deux phases).
  2. Relaxation infaisable : élaguer le nœud.
  3. Borne ≤ incumbent : élaguer (aucune amélioration possible).
  4. Solution entière : mettre à jour l'incumbent, élaguer.
  5. Sinon brancher sur une variable fractionnaire \(x_j\) : fils \(x_j \le \lfloor x^*_j \rfloor\) et \(x_j \ge \lceil x^*_j \rceil\).
  6. Nœud suivant : meilleure borne (best-bound). Terminer quand la file est vide.
